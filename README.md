# 🎨 Shape System

A simple C# console application created to demonstrate the core concepts of **Object-Oriented Programming (OOP)** using different geometric shapes.

## 📌 Overview

This project uses a base `Shape` class and several derived classes to demonstrate how **inheritance** and **polymorphism** work in C#.

Each shape has its own implementation of the `Draw()` method.

### Supported Shapes

- 🔵 Circle
- 🔺 Triangle
- ▭ Rectangle
